# 라이프플랜

우리 집 자산·현금흐름·은퇴 계획을 한 화면에서 보는 웹앱입니다.
**데이터는 이 기기의 브라우저에만 저장**되고 어떤 서버로도 보내지 않습니다.

- 실행: https://rcntiger.github.io/lifeplan/
- 휴대폰: 크롬(안드로이드) 메뉴 → 홈 화면에 추가 / 사파리(아이폰) 공유 → 홈 화면에 추가

## 처음 쓰기
처음 열면 7단계 설정 마법사가 나옵니다.

1. 가구 — 1인 / 부부, 자녀 수, 함께 계획할 부모님 수
2. 나 — 닉네임, 생년월일, 직업, 월 실수령액, 퇴직·연금 시기와 예상 연금
3. 배우자 (부부일 때)
4. 자녀 — 이름, 생년월일
5. 부모님 — 이름, 생년월일, 연금 등 소득, 드리는 부양비
6. 자산·부채
7. 매달 나가는 돈, 은퇴 후 생활비, 예상 수익률

모르는 칸은 비워 두고 나중에 각 탭에서 고치면 됩니다. **예시로 둘러보기**를 누르면 가상의 가구로 화면을 먼저 볼 수 있습니다.

## 화면
| 탭 | 내용 |
|---|---|
| 대시보드 | 순자산, 자산 비중, 이번 달 현금흐름, 다가오는 목돈 |
| 가족 | 구성원(자녀·부모 포함), 소득 있음/없음·가계 포함, 생애 타임라인, 가족 나이 |
| 자산 | 자산·부채 목록 |
| 예산 | 금융자산을 ① 생활 예비 ② 공백 대비 ③ 장기투자로 나눠 목표와 비교 |
| 자금흐름 | 수입(급여 장부·월 소득 항목) · 지출(고정지출·목돈) · 흐름(연도별 소득·생활비, 저축 여력) |
| 시뮬 | 은퇴 후 금융자산 추이 (물가를 뺀 실질 기준) |
| 할 일 | 체크리스트 |

소득이 있는 자녀·부모는 명의를 가질 수 있고, **가계에 포함**한 사람의 소득·지출만 현금흐름·예산·시뮬레이션에 더해집니다.

직업을 **공무원·교사·군인**으로 고르면 본봉으로 명절휴가비·연가보상비를 자동계산하는 기능이 켜집니다.

## 데이터 보관
- 장부는 이 기기 브라우저(localStorage)에만 있습니다. 폰을 바꾸거나 브라우저 데이터를 지우면 사라집니다.
- ⚙ 설정 → **백업 파일 저장**으로 JSON 파일을 받아 두세요. 30일이 지나면 대시보드에서 알려 줍니다.
- 배우자와 함께 쓰려면 백업 파일을 주고받아 **백업 불러오기 → 합치기**를 고르세요. 내 장부에 없는 항목만 더해집니다.

## 주의
계산은 단순화한 추정이며 투자·세무·법률 조언이 아닙니다. 연금·세금은 국민연금공단, 공무원연금공단, 국세청 등에서 확인하세요.

## 만든 방식
HTML 파일 하나(외부 라이브러리 없음) + PWA(manifest, service worker). GitHub Pages로 배포합니다.
